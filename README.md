# Сервис управления рассылками

Веб-приложение на Django для управления email-рассылками с разделением прав доступа, кешированием и историей отправок.

---

## Функциональность

### Для всех пользователей
- Регистрация с подтверждением email
- Восстановление пароля через email
- Просмотр общей статистики сервиса (неавторизованные)

### Для авторизованных пользователей
- Управление клиентами (CRUD) — только свои
- Управление сообщениями (CRUD) — только свои
- Управление рассылками (CRUD) — только свои
- Отправка писем по требованию (только владелец)
- Логирование попыток отправки (успех/неуспех)
- Персональная статистика на главной странице
- Автоматическое обновление статуса рассылки по времени:
  - `created` → `started` → `completed`

### Для менеджеров
- Просмотр всех данных (клиенты, сообщения, рассылки)
- Отправка любых рассылок
- **НЕТ** прав на редактирование и удаление данных

### Технические особенности
- Кеширование главной страницы (30 секунд) с `vary_on_cookie`
- Клиентский `Cache-Control` (`max-age=30, stale-while-revalidate=10`)
- Разделение статистики для авторизованных и неавторизованных пользователей
- История попыток отправки на странице деталей рассылки

## Установка и запуск

### 1. Клонировать репозиторий

git clone https://github.com/ваш_логин/coursework_django.git
cd coursework_django

### 2. Создать виртуальное окружение

python -m venv venv
venv\Scripts\activate   # Windows
source venv/bin/activate # Linux/Mac

### 3. Установить зависимости

pip install -r requirements.txt

### 4. Настроить базу данных PostgreSQL
Создайте базу данных coursework_db и настройте .env:


NAME=coursework_db
USER=postgres
PASSWORD=ваш_пароль
HOST=localhost
PORT=5432

### 5. Настроить email (для разработки)
В settings.py уже настроен вывод писем в консоль:

python
EMAIL_BACKEND = 'django.core.mail.backends.console.EmailBackend'
DEFAULT_FROM_EMAIL = 'admin@example.com'



### 6. Применить миграции

python manage.py migrate

### 7. Создать суперпользователя

python manage.py createsuperuser

### 8. Создать группу "Менеджер"
Зайдите в админку /admin/ и создайте группу с именем "Менеджер".

### 9. Запустить сервер

python manage.py runserver
